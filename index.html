如何获取授权码

打开 GitHub 授权码设置，选择 Only select repositories，仅勾选 yuliang-ledger-backup。将 Contents 设为 Read and write，生成后粘贴到下方。

授权码保存在当前设备的网站数据中。请勿把授权码发到聊天里；共用设备可点击清除。

安全备份

日常记录保存在当前设备的浏览器中。清除网站数据或更换手机会丢失本地账本，请定期导出到「文件 / iCloud」。不同设备不会自动同步。

导入将替换当前账本，并保留一次本地恢复副本。建议先导出当前账本。
