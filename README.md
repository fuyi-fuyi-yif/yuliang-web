# 余量 Web

手机优先、可离线的个人记账 PWA。手动记录支出、退款与转账，分类预算、月度概览、搜索与 JSON 备份。兼容余量 iOS 的整数分账本格式及 2026 年底专项计划。

## 使用
Safari 打开部署网址 → 分享 → 添加到主屏幕 → 从主屏幕启动 → 预算与备份 → 导入账本。首次联网加载完成显示「离线可用」后可以离线记账。

账本只保存在当前浏览器的 IndexedDB，可手动备份到指定 GitHub 私有仓库，或从该仓库恢复。清除网站数据、卸载或浏览器回收存储可能丢失数据，务必定期导出到文件/iCloud。应先安装再导入，Safari 与主屏幕运行环境可能使用不同存储。恢复按钮保留最近一次写入前的快照，不替代外部备份。

GitHub 备份使用仅限账本仓库的 fine-grained token（Contents 读写）。授权码保存在当前设备的浏览器网站数据中，可在设置页清除。Safari 与主屏幕版在 iOS 上可能分别存储账本及授权码，可通过私有仓库备份和恢复转移。

## 开发与发布
无运行时依赖。`npm test` 验证核心计算；`npm run dev` 在本机预览。GitHub Pages 从 main 分支根目录发布。所有资源使用相对路径，支持项目子目录。修改静态资源后递增 sw.js 缓存版本，旧窗口关闭后新版本生效。发布文件中不应包含真实账本、备份或凭据。

预算默认空白。年预算按月均摊为参考，不代表实际缴费日期。导入替换账本前会明确确认，所有金额以整数分保存，未知字段保持不变。记录不按金额和日期去重，允许真实重复消费。
